This directory is a small Python CLI, `wordfreq` (see README.md). Add a new option `--exclude-file PATH` to the CLI: PATH is a text file with one word per line; blank lines and lines starting with `#` are ignored, surrounding whitespace is stripped, and matching is case-insensitive. Words listed in that file must be dropped from the counts before ranking, so `--top N` still shows N words (the top N of the remaining ones). Without the flag, behaviour is unchanged. If PATH does not exist, print an error message to stderr and exit with status 2. Also add at least one new pytest test for the feature under `tests/` (name it so that it mentions "exclude"), keep the existing tests passing, and update the README. Run the tests with `python3 -m pytest` (pip install pytest if missing).
