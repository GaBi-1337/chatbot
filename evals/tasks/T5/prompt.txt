The `shop` package in this directory prices orders, and it keeps every money amount as a float number of dollars. We keep running into rounding errors, so please convert it to integer cents throughout: every function, method, attribute and constant that takes, returns or holds a money amount should use int cents (catalog prices, Cart totals, discounts, shipping, tax, the invoice fields, the revenue report). Rates and percentages stay as they are.

Put the money helpers in a new module `shop/money.py`: `parse_dollars(text) -> int` (so "12.50" gives 1250 and "$1,234.5" gives 123450; raise ValueError for anything that is not a dollar amount or has more than two decimal places) and `format_cents(cents) -> str` (1234550 gives "$12,345.50", -320 gives "-$3.20"), and remove `shop/util.py`. Percentage-based amounts (tax, bulk and coupon discounts, the average order value) must round half up to the nearest cent, computed without floats.

The command line interface keeps taking dollars (for example `--credit 5.50`) and its output must stay byte-for-byte identical; examples to try are in `examples/`. Update the tests under `tests/` to the new units and add tests for the new module. Run the tests with `python3 -m pytest` (pip install pytest if missing).
